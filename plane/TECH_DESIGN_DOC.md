#LYD的飞机大战
## 飞机大战网页游戏技术设计文档 v1.0

---

## 一、项目概述

### 1.1 游戏名称
LYD的飞机大战

### 1.2 游戏类型
竖版射击类网页游戏

### 1.3 目标平台
现代浏览器 (Chrome, Firefox, Safari, Edge)，HTML5 Canvas 2D，自适应屏幕

### 1.4 设计目标
- **视觉效果**：赛博朋克科技风格，霓虹光效，粒子特效丰富
- **玩法深度**：融合市面爆火飞机大战的核心玩法（强化系统、技能、蓄力、大招、僚机等）有小兵有Boss有关卡有结局
- **Boss战**：每章节末大型Boss，多形态、多阶段、弹幕地狱
- **可扩展性**：模块化架构，方便后续增加关卡、飞机、Boss

### 1.5 参考爆火玩法
| 来源游戏 | 借鉴玩法 |
|---------|---------|
| 《雷电》系列 | 经典纵向卷轴、武器等级系统、保险Bomb |
| 《东方Project》 | 高密度弹幕、擦弹系统、Spell Card（符卡）机制 |
| 《1945》 | 僚机系统、飞机选择、多结局分支 |
| 《全民飞机大战》(手游) | 装备强化、宠物/僚机、技能CD、无尽模式、好友排行 |
| 《Phoenix 2》 | 每日任务、Boss Rush、飞船收集 |

## 二、技术选型

### 2.1 核心技术栈
| 层级 | 技术选型 | 说明 |
|------|---------|------|
| **渲染引擎** | HTML5 Canvas 2D | 原生Canvas，无需额外库，性能可控 |
| **编程语言** | 原生 JavaScript (ES6+) | 无构建步骤，solo builder开箱即用，或用TypeScript可选 |
| **模块管理** | ES Modules (import/export) | 现代浏览器原生支持，代码模块化 |
| **音频** | Web Audio API | 合成音效 + Audio元素播放BGM |
| **输入** | Pointer Events (鼠标/触屏) + Keyboard | PC端键鼠，移动端触屏拖动 |
| **存档** | localStorage | 本地存档：最高分、飞机解锁、装备 |
| **状态管理** | 简单有限状态机 (FSM) | 游戏状态：菜单/游戏中/暂停/Boss战/结算 |

### 2.3 不使用外部依赖的理由
- **Solo Builder友好**：无需npm install、无需构建工具，双击index.html即玩
- **性能可控**：Canvas 2D足够处理数百子弹+粒子
- **绘制风格统一**：用Canvas API程序化绘制几何图形+发光特效，完美契合科技风格，避免素材版权问题

## 三、游戏核心系统设计

### 3.1 游戏循环 (Game Loop)
```
┌─────────────────────────────────────────────────────┐
│  requestAnimationFrame 60FPS                        │
│  ┌─────────┐  ┌──────────┐  ┌──────────┐           │
│  │  Input  │→│  Update  │→│  Render  │           │
│  │  输入   │  │  逻辑更新│  │  画面渲染│           │
│  └─────────┘  └──────────┘  └──────────┘           │
│         ↓              ↓              ↓             │
│    键鼠/触屏    移动/碰撞/AI    Canvas绘制+特效     │
└─────────────────────────────────────────────────────┘
```
- **固定时间步长**：用deltaTime保证不同帧率下逻辑一致
- **分层渲染**：背景层(视差) → 敌人层 → 子弹层 → 玩家层 → 粒子层 → UI层

### 3.2 状态机 (FSM)
```
MAIN_MENU ←→ HANGAR（机库）
    ↓
  PLAYING ←→ PAUSED
    ↓
 BOSS_BATTLE（子状态，属于PLAYING）
    ↓
  RESULT（胜利/失败）→ MAIN_MENU
```

### 3.3 输入系统
| 操作 | PC端 | 移动端 |
|------|------|--------|
| 移动 | 鼠标拖动 / WASD / 方向键 | 手指触屏拖动（战机跟随手指，有偏移避免遮挡） |
| 射击 | **自动开火**（默认开启，可按J关闭） | 自动开火 |
| 蓄力 | 长按左键 / K键 | 长按屏幕（需区分：滑动移动 vs 原地长按蓄力） |
| 必杀Bomb | 空格 / Q键 | 右下Bomb按钮 |
| 技能1 | E键 | 右下技能按钮1 |
| 技能2 | R键 | 右下技能按钮2 |
| 暂停 | ESC / P键 | 暂停按钮 |

## 四、玩家战机系统

### 4.1 玩家可选飞机（3架起步，可解锁）
| 飞机代号 | 名称 | 定位 | 特性 | 主武器 | 必杀技 | 被动技能 |
|---------|------|------|------|--------|--------|---------|
| **SF-01** | 猎鹰 (Falcon) | 均衡型 | 新手友好，性能全面 | 双发直线弹，强化后变为三向+散射 | 🎯 激光扫射：全屏水平激光，瞬间清屏小怪 | 击杀回复能量+5% |
| **SF-02** | 雷霆 (Thunder) | 火力型 | 单发伤害高，弹速慢，移动慢 | 重型穿甲弹，强化后6联装 | 💥 电磁脉冲：范围AOE+麻痹敌人2秒 | 蓄力攻击伤害+30% |
| **SF-03** | 幻影 (Phantom) | 技巧型 | 移动快，判定点小，擦弹加分 | 多方向追踪弹 | ⚡ 时停领域：时间减速3秒+无敌 | 擦弹获得额外分数和能量 |

### 4.2 战机属性
```javascript
{
  hp: 100,           // 生命值（0死亡）
  maxHp: 100,
  speed: 6,          // 移动速度（像素/帧）
  power: 1,          // 火力等级 1~8
  bomb: 3,           // 必杀次数
  energy: 100,       // 技能能量 0~100
  hitboxRadius: 4,   // 碰撞判定点（小圆，比机身小，躲避弹幕友好）
  grazeRadius: 24,   // 擦弹判定圈
}
```

### 4.3 火力强化系统 (Power Up)
- **道具P**：拾取后火力等级+1（最高Lv.8）
- **强化路径**：
  - Lv1-2：基础直射
  - Lv3-4：增加僚机、副武器
  - Lv5-6：弹幕变宽、增加弹道
  - Lv7-8：弹幕颜色升级为金色+穿透效果

### 4.4 蓄力攻击
- **操作**：按住射击键（或长按屏幕）不移动
- **机制**：
  - 蓄满时间：1.5秒，UI显示蓄力条
  - 释放：发射一发巨型能量弹，伤害=普通弹×20，穿透敌人
  - 幻影机蓄力：额外产生8方向追踪弹

### 4.5 必杀技 (Bomb) 系统
- **触发**：使用后立即清除屏幕内所有敌方子弹，并对Boss造成大伤害
- **无敌帧**：使用后玩家1.5秒无敌
- **视觉**：全屏闪白+冲击波粒子扩散+屏幕震动

### 4.6 僚机系统 (Wingman)
- **获取**：火力Lv.3后自动部署1架僚机，Lv.5部署2架
- **位置**：跟随玩家，左右对称分布在玩家后上方
- **攻击**：僚机发射小型弹，伤害是主机的30%
- **可配置**：机库中选择僚机类型（攻击型/防御型/辅助型）

## 五、敌机与Boss系统

### 5.1 敌机类型
| 类型 | 名称 | 行为 | 掉落 |
|------|------|------|------|
| **小型机** | 侦察机 Drone | 直线俯冲，或S型走位，血量低，1-2发击落 | 小概率P/金币 |
| **中型机** | 突击者 Striker | 停下射击扇形弹幕，血量中 | 大概率P/小概率血包 |
| **精英机** | 精英 Elite | 多段弹幕（螺旋/环形），血量高，有血条显示 | 必掉1个P+1个随机道具 |
| **轰炸型** | 轰炸机 Bomber | 移动慢，血量高，发射慢速大弹 | 掉血包+金币 |
| **自杀式** | 神风 Kamikaze | 追踪玩家高速撞击，血量低 | 小概率能量 |

### 5.2 Boss战设计（核心亮点）

#### 通用Boss机制
1. **多阶段 (Phase)**：每只Boss 3个阶段，血量低于66%/33%时切换阶段
2. **阶段转换特效**：屏幕红闪+警告音+"WARNING"横幅+攻击模式刷新
3. **弹幕进化**：每阶段弹幕密度和复杂度提升
4. **Spell Card（符卡）**：每阶段有名字的大招弹幕（致敬东方Project）
5. **弱点部位**：Boss有核心发光点，击中造成×2伤害
6. **时间奖励**：快速击破符卡可获得大量分数+道具奖励

#### Boss1：机械巨蟹 (Mecha Crab) — 第1关
- **体型**：中大型，占屏幕上方40%
- **阶段设计**：
  - **Phase 1 (100%~66%)**：巨蟹钳左右夹击 + 双向扇形弹
  - **Phase 2 (66%~33%)**：召唤4个浮游炮（四角）+ 8方向环形弹
  - **Phase 3 (33%~0%)**：全身发光，旋转激光十字+追踪弹雨
- **视觉**：红色机械外壳，液压关节动画，眼睛发光

#### Boss2：量子母舰 (Quantum Carrier) — 第2关
- **体型**：超大型，占屏幕上方60%，有多个子模块
- **阶段设计**：
  - **Phase 1**：两舷导弹巢齐射（抛物线导弹）+ 前部双联炮散射
  - **Phase 2**：展开甲板，释放3波小型机编队 + 电磁脉冲环（扩散圈弹）
  - **Phase 3**：中心量子核心暴露，发射螺旋弹幕（三层反向旋转）+ 瞬移到左右两侧
- **视觉**：深蓝色量子发光外壳，数据流动画，传送时粒子消散

#### Boss3：深渊吞噬者 (Abyssal Devourer) — 第3关（终极Boss）
- **体型**：巨型，分段式，蛇形移动
- **阶段设计**：
  - **Phase 1**：蛇身波状运动，每节发射自机狙（瞄准玩家的弹）
  - **Phase 2**：头部张开巨口，喷射扇形激光+环形弹幕壁（压迫式）
  - **Phase 3【最终形态】**：全屏弹幕地狱（弹幕密度参考东方Lunatic难度）+ 随机黑洞（吸引玩家）+ 召唤2个护卫精英
- **视觉**：紫黑色虚空质感，触手/能量管道动画，周围星空扭曲

### 5.3 波次生成 (Spawner)
- 关卡采用**时间轴+事件触发**方式
- 配置示例 (WaveData)：
  ```
  0s~5s    : 静默期，只有背景
  5s       : 生成8架小型机（V型编队，从上方入场）
  12s      : 生成2架中型机（左右两侧）
  20s      : 精英机出场
  35s      : 轰炸编队
  50s      : 小BOSS（可选）
  70s      : BOSS WARNING → 进入Boss战
  ```

## 六、弹幕系统 (Bullet Hell)

### 6.1 子弹类型枚举
| 类型 | 描述 | 视觉 |
|------|------|------|
| `NORMAL` | 普通直线弹 | 小圆/椭圆，发光描边 |
| `AIMED` | 自机狙（追踪玩家方向） | 带箭头指示 |
| `LASER` | 激光（持续伤害，快速穿过） | 细长光束，闪烁 |
| `SPIRAL` | 螺旋弹 | 彩色螺旋轨迹 |
| `CIRCLE` | 环形弹（N发均匀360度） | 环形扩散 |
| `FAN` | 扇形弹（N发在指定角度范围内） | 扇形扩散 |
| `WAVE` | 正弦波弹 | 曲线运动 |
| `BIG` | 大弹（碰撞体积大，伤害高） | 大光球 |
| `RANDOM` | 随机散射弹 | 混乱弹幕 |

### 6.2 弹幕生成API示例（Builder需实现）
```javascript
// 发射环形弹：中心(x,y)，数量24发，速度2px/帧
bulletHell.spawnCircle(x, y, { count: 24, speed: 2, color: '#ff00ff' });

// 发射扇形弹：朝向angle，开角60度，12发
bulletHell.spawnFan(x, y, angle, { count: 12, spread: Math.PI/3, speed: 3 });

// 发射螺旋弹：每次旋转deltaAngle，持续生成
bulletHell.spawnSpiral(x, y, { duration: 3000, speed: 2.5, rotationSpeed: 0.1 });
```

### 6.3 擦弹系统 (Graze)
- 玩家周围有**擦弹圈**（半径24px）> 判定点（半径4px）
- 敌方子弹进入擦弹圈但未击中判定点 → 触发擦弹
- **效果**：
  - +10分/次擦弹
  - +1点能量/次擦弹
  - 视觉：子弹擦过位置有蓝色小火花 + 屏幕边缘微弱闪烁
  - 连击：连续擦弹在HUD显示"GRAZE x12"连击数

## 八、关卡与游戏模式

### 8.1 关卡模式（剧情）
| 关卡 | 名称 | 背景主题 | 时长 | Boss |
|------|------|---------|------|------|

### 8.2 无尽模式 (Endless)
- 通关后解锁
- 波次循环，难度递增（敌机血量+20%/轮，弹幕数量+15%/轮）
- 排行榜（本地localStorage记录前10名）
- 每5波出现Mini Boss，每20波出现随机Boss

### 8.3 挑战模式 (Challenge) — 预留扩展位
- Boss Rush：连续打3个Boss，血量继承，无补给
- 弹幕挑战：限定飞机，打特定高密度符卡

## 十二、关键实现提示（给Solo Builder）

### 12.1 性能优化要点
1. **对象池 (Object Pool)**：子弹、粒子、敌人频繁创建销毁，必须用对象池复用，避免GC卡顿
2. **空间分区碰撞**：用网格(Grid)或四叉树(QuadTree)，不要O(n²)两两碰撞
3. **Canvas离屏缓存**：静态背景（星空、网格）画在离屏Canvas，每帧只blit一次
4. **粒子上限**：同屏粒子≤300，超出则淘汰最老的

### 12.2 对象池示例结构
```javascript
class ObjectPool {
  constructor(createFn, initialSize = 50) {
    this.pool = [];
    this.createFn = createFn;
    for (let i=0; i<initialSize; i++) this.pool.push(createFn());
  }
  acquire() { return this.pool.pop() || this.createFn(); }
  release(obj) { obj.active = false; this.pool.push(obj); }
}
```

### 12.3 碰撞检测
- **圆形碰撞**（所有实体都是圆）：`distance² < (r1+r2)²`，避免开根号
- **子弹碰撞简化**：敌方子弹只和玩家判定点检测；玩家子弹只和敌机碰撞盒检测

### 12.4 屏幕震动
```javascript
// 震动参数：{ intensity: 10, duration: 500 }
// 实现：每帧对ctx.translate()偏移一个随机值（基于时间衰减）
```

### 12.5 数据驱动
- **所有敌机/Boss数据**放在 `config/*.js`，不要硬编码在逻辑里
- **关卡波次**用数组声明式写法，方便后期调整数值
